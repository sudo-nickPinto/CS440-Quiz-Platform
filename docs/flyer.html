About the project

QuizBurg is a live quiz platform built for Gettysburg College classrooms. Instructors create quizzes, organize them into classes, and build reusable question banks that can be imported from or exported to CSV. When it is time to play, the host starts a live session and shares a short join code; students answer from their phones or laptops, and every response appears on the host's screen in real time. After the session, students review their own answers, score and rank, while hosts view and export the full results.
